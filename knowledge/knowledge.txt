/*
终极答案：优先从 resources 下找，但你现在是从 src 下找到的！
底层真相：
classpath: = 编译后的 target/classes 目录
  Maven + SpringBoot 插件会自动把两个地方都打进 classpath：
  src/main/java 下的 .xml
  src/main/resources 下的所有文件

  你的 XML 实际位置：
  plaintext
  src/main/java/com/atguigu/srb/core/mapper/xml/*.xml
  但 SpringBoot 会自动把它复制到：
  plaintext
  target/classes/com/atguigu/srb/core/mapper/xml/
  所以配置
  yaml
  classpath:com/atguigu/srb/core/mapper/xml/*.xml
  才能找到！
  最直白总结（背会）
  classpath 不是 src，也不是 resources
  classpath = target/classes
  SpringBoot 会自动把 java 目录和 resources 目录的文件都放进 target/classes
  所以你写的配置能找到 src 下的 XML
*/

但是一般来说，安全起见，需要将
<build>
    <!-- 项目打包时会将java目录中的*.xml文件也进行打包 -->
    <resources>
        <resource>
            <directory>src/main/java</directory>
            <includes>
                <include>**/*.xml</include>
            </includes>
            <filtering>false</filtering>
        </resource>
    </resources>
</build>放到pom里面

因为maven工程在默认情况下src/main/java目录下的所有资源文件是不发布到target目录下的，
因此我们需要在pom.xml中添加xml配置文件发布配置
